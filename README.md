# Frontend Internship Task 2

## Project Title

Interactive To-Do List Web Application

## Objective

The objective of this project is to demonstrate core frontend development
concepts using HTML, CSS and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Web Browser
- Git
- GitHub

## Features

- Add new tasks
- Complete tasks
- Delete tasks
- Empty input validation
- Dynamic task counter
- Responsive layout

## Core Concepts Demonstrated

### HTML

Used HTML to create the structure of the application including:

- Heading
- Input field
- Buttons
- Task list

### CSS

Used CSS for:

- Box model
- Flexbox
- Colors
- Spacing
- Borders
- Shadows
- Responsive design

### JavaScript

Used JavaScript for:

- Variables
- Arrays
- Objects
- Functions
- Conditions
- DOM manipulation
- Event handling

## Testing

The application was tested by adding, completing and deleting
multiple tasks and by checking empty input validation.

## Conclusion

This project helped demonstrate practical understanding of
frontend development concepts and improved my ability to create
interactive web applications using HTML, CSS and JavaScript.
